## 🚦 Getting Started on the Water

This is not a plug-and-play script; it is a modular framework designed for the discerning user. 

1. **Prerequisites**: Ensure your game client is updated to the latest seasonal patch. We actively support the most recent build.
2. **Deployment**: Place the module files in your preferred script loader’s directory. Our intuitive configuration panel (accessible via the in-game console) lets you toggle each feature independently.
3. **Configuration**: The `settings.ini` file is human-readable. Adjust the `WealthMultiplier` from `1.0` to `10.0` to fine-tune the immersion level. We recommend a value of `3.5` for a balanced experience.
